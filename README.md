# 소문의 낙원 미션 인증

2026 시냇가푸른청년교회 하반기 새생명축제(11.29) 미션 인증 사이트.

- `index.html` 참가자 인증 페이지 (이름 · 마을 · 전화 뒷자리, 미션 1~5 중복 선택, 사진 최대 3장, 내 도장판)
- `admin.html` 관리자 페이지 (승인/반려, 참가자별·미션별 현황, 엑셀 다운로드)
- `config.js` 사이트 설정 — `API_URL`에 구글 Apps Script 웹 앱 주소를 넣으세요
- `apps-script/Code.gs` 구글시트에 붙여넣는 서버 코드 (데이터는 구글시트, 사진은 구글드라이브)

`API_URL`이 비어 있으면 예시 데이터로 도는 미리보기 모드예요. (관리자 비밀번호 `demo`)

자세한 설치 방법은 함께 드린 설치 가이드 PDF를 보세요.
